已部署：baseball-analysis v35（T-10）、baseball-v2-stage-runner v2（T-2／T-15）。已重新讀回線上原始碼，兩者均與此目錄版本逐字一致。

## 計算內容

三階段共用 mlb-player-adjustment.js。已公布的九人打線，依各打者本季 OPS 與打席數計算，向球隊基準收縮小樣本，再修正原模型的進攻部分。打線未公布時，具有效樣本的傷兵打者以現役替補樣本估計影響。正式打線與打者傷兵修正互斥，避免重複計算缺陣。

牛棚傷兵另以本季投球樣本及現役後援池估計對方得分修正。預估先發若同時列為確定缺陣，不採用該投手原先的 ERA 修正。先發輪值替代人選未公布時不虛構投手資料。

OPS 與得分的換算、打席／局數收縮量及修正上限為保守啟發式設定，尚未完成預測準確度回測；不能以功能測試通過代替準確度驗證。

## 資料保護

- 僅使用球隊、球季相符的球員統計；重複分列不任意挑選。
- 打線缺員、傷停與打線衝突、替補樣本不足時跳過該修正，保存原因。
- 目前的 API 統計不冒充過去的賽前資料。
- 已封存、已領取的分析不重算、不改寫。
- 單場與批次仍讀取同一份階段快照，未更動扣點流程。
